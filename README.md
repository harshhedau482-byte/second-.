  # Pattern Generator and Number Analyzer (Python)

## 📖 Project Description

This is a basic Python program created for beginners. It allows users to:

- Generate different star (`*`) patterns.
- Analyze numbers in a given range.
- Check whether numbers are even or odd.
- Calculate the sum of numbers in a range.
- Exit the program.

---

## ✨ Features

### Pattern Generator
The program can print:

1. Left Triangle
2. Reverse Right Triangle
3. Right Triangle
4. Inverted Left Triangle
5. Pyramid Pattern

### Number Analyzer
- Checks whether each number is **Even** or **Odd**.
- Calculates the **sum** of all numbers in the given range.

---
